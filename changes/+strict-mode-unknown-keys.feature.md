Added `strict="off" | "warn" | "error"` to `load()`, `Loader`, `Dature`, and per-`Source` (with a `DATURE_LOADING__STRICT` env var / `LoadingConfig.strict` default, and source > load > config precedence). After a successful load, compares the keys each source actually contributed against the schema — accounting for `NameStyle` variants and `field_mapping` aliases, and scanning through `list`/`dict`/`tuple` containers into nested dataclasses — and reports any unmatched key as a warning or a `StrictModeError`, with the source's file and line location. `EnvSource` warns when strict mode is on without a `prefix`, since without one every process environment variable is a candidate key. The number of unknown-key blocks shown is capped by `error_display.max_errors`, independent of `max_visible_lines` (how many lines of source content one block shows); beyond the cap, a note gives the true total.
