A dataclass field whose `default_factory` requires arguments (e.g. `tg: TgConfig = field(default_factory=TgConfig)` where `TgConfig` has required fields) can never actually be filled in by that default, so it is now treated as required — exactly like the same field declared without `default_factory`. An absent (or only partially filled) section now raises the normal "missing required field" error for every missing subfield, enriched with which `default_factory` could not help, instead of letting a bare `TypeError` from the factory call leak out. This also fixes an existing gap where only the first missing subfield of a partially-filled section was reported — every missing subfield, and any unrelated validator failures elsewhere in the schema, are now reported together.
