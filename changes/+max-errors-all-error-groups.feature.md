`error_display.max_errors` (`DATURE_ERROR_DISPLAY__MAX_ERRORS`) now caps every dature exception group, not just strict mode's unknown-key errors: validation failures, merge conflicts, field-group violations, env-var expansion errors, and cross-source reference errors are all capped at `max_errors` blocks, with an `... and N more <kind> (M total)` note for the rest. Previously only strict mode honored this setting — a schema with many invalid fields, for example, would print every one of them.
